## الهدف
لائحة مواقعك داخل الاستوديو، وزر «ابدأ» يشتغل بدون توقف: كل موقع يُسجَّل فيديو أطول من ٣ دقائق بجودة عالية، ويُحفظ مع نصه باسم الموقع في مجلد تختاره أنت، ثم ينتقل تلقائياً للموقع التالي.

## 1) لائحة المواقع
- استخراج كل الروابط وتعريفاتها من `site_groupe_hn.txt` إلى `src/data/sites.ts` (`{ url, name, description }`) مع إزالة التكرارات.
- لوحة اختيار: بحث + تحديد متعدد + «اختيار الكل» + ترتيب الطابور.
- خانة «إضافة موقع جديد»: تلصق رابطاً فيُضاف للطابور ويُولَّد نصه من محتوى صفحته.

## 2) مدة كل فيديو ≥ ٣ دقائق
- المدة الافتراضية ١٩٥ ثانية (٣:١٥) مع خيارات ٣ / ٤ / ٥ دقائق.
- كيف نملأ الوقت بمحتوى حقيقي لا بفراغ:
  - توسيع الجولة تلقائياً لتشمل صفحات أكثر (اكتشاف حتى ١٠–١٢ مساراً) وتقسيم الوقت بينها.
  - إن كان الموقع بصفحة واحدة: تمرير سينمائي أبطأ بوقفات قراءة عند كل قسم، وتكبير/تصغير خفيف، ولقطات عودة لأعلى.
  - مقدمة قصيرة وخاتمة ببطاقة اسم الموقع والرابط.
- النص يُكتب بطول المدة: ≈ ٢.٤ كلمة/ثانية → ٣:١٥ ≈ ٤٧٠ كلمة، مقسّمة على الصفحات.
- ضبط دقيق: يُقاس طول الصوت الفعلي وتُمدَّد أو تُقصَّر وقفات الصفحات حتى يتطابق الصوت مع الفيديو تماماً ولا ينتهي قبل ٣ دقائق.

## 3) زر «ابدأ» — تشغيل متواصل
- تسجيل الموقع الأول → إيقاف → تحويل MP4 → حفظ الفيديو والنص → الانتقال فوراً للتالي بلا ضغطة إضافية.
- مشاركة الشاشة تُطلب مرة واحدة فقط.
- لوحة تقدّم: «٣ من ٢٠»، حالة كل موقع، زر إيقاف، ومتابعة تلقائية عند الفشل.

## 4) مجلد الحفظ `E:\site presentation`
- زر «اختر مجلد الحفظ» يفتح نافذة النظام، تختار المجلد مرة واحدة، وبعدها تُكتب كل الملفات فيه تلقائياً (File System Access API في Chrome/Edge)، ويُحفظ الاختيار للجلسات القادمة. وإلا يعود التنزيل للمجلد الافتراضي.

## 5) جودة أعلى وشاشة أكبر
- منطقة العرض ~٩٠٪ من عرض الشاشة، واللوحات الجانبية تنطوي أثناء التسجيل.
- مستوى «4K 2160p» حتى ٤٠ ميغابت/ث بجانب 1080p/1440p، ٦٠ إطاراً/ث، تفضيل ترميز H.264 عند دعمه، صوت 192kbps، و`contentHint = "detail"` لنص أوضح.
- ملاحظة: ٣ دقائق بجودة 4K تعني ملفات كبيرة (~٨٠٠ ميغابايت) ووقت تحويل أطول؛ الافتراضي سيكون 1080p/60 وهو الأنسب ليوتيوب.

## 6) النص أسفل الفيديو + الصوت
- تمرير الشاشة عبر Canvas ورسم شريط نص سفلي (عربي RTL، خلفية شبه شفافة) — محروق داخل MP4.
- قراءة صوتية آلية متزامنة، والنص يتقدّم جملة بجملة. النص الطويل يُقسَّم لمقاطع صوتية متتالية.

## 7) الملفات لكل موقع
- `hn-cinema.mp4`، `hn-cinema.txt` (النص + الرابط + المدة + وسوم يوتيوب)، و`hn-cinema.srt`.

## 8) وضع «النص فقط»
- تلصق روابط مواقع جديدة (سطر لكل رابط) → تُولَّد النصوص فقط بطول ٣ دقائق وتُحفظ كملفات `.txt`.

## تفاصيل تقنية
- `src/data/sites.ts`؛ `src/lib/script.ts` (حساب الكلمات/التوقيتات، txt وsrt)؛ `src/lib/fs-save.ts` (مجلد الحفظ)؛ `src/lib/narration.functions.ts` (نص بطول مستهدف + TTS مقسّم)؛ `src/lib/tour.ts` (توزيع المدة على الصفحات وضمان الحد الأدنى)؛ `src/routes/studio.tsx` (Canvas، الطابور، زر ابدأ، تخطيط ٩٠٪، الجودة).
- بدون تبعيات مدفوعة جديدة.
