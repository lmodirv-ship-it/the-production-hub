# خطة البناء — منصة "Eco AI" لتوليد فيديوهات الشرح التلقائية

سأبني تطبيق ويب عربي (RTL) كامل وقابل للإنتاج، مستوحى من الصورة المرجعية، مع لمسة تصميم فريدة (بنفسجي عميق + نيون سماوي، خطوط Tajawal/Space Grotesk).

## ما سيتم بناؤه

**صفحة رئيسية واحدة قوية** + **لوحة استوديو** + **حساب مستخدم**.

### 1. الواجهة (Frontend, RTL عربي)
- Landing مختصرة: عنوان بطل + شريط إدخال رابط موقع + 3 مزايا + CTA.
- صفحة Auth (تسجيل/دخول بالبريد + Google).
- صفحة Studio بـ 4 لوحات كما في الصورة:
  - **Voice & Audio**: اختيار صوت (4 أصوات)، لغة، Pitch، Speed، زر معاينة.
  - **AI Video Generation**: شريط تقدم render + حالة.
  - **Video Preview**: مشغل فيديو/صوت مع waveform.
  - **Scene Editor**: نص السكربت لكل مشهد قابل للتعديل + صور توضيحية مولّدة.
  - **Timeline**: شرائح المشاهد (Scene 1..N) قابلة للسحب/التنشيط.
- صفحة "مشاريعي" لعرض المشاريع المحفوظة.

### 2. الخلفية (Backend عبر Lovable Cloud)
- **قاعدة بيانات**: جداول `profiles`, `projects`, `scenes`, `renders`, مع RLS.
- **Storage**: لحفظ ملفات MP3 الصوتية وصور المشاهد.
- **Server Functions** (TanStack Start):
  - `scrapeUrl`: جلب نص الموقع (fetch + استخراج).
  - `generateScript`: Lovable AI (gemini-3-flash) → سكربت 4-6 مشاهد JSON.
  - `generateSceneImages`: Lovable AI image generation لكل مشهد.
  - `generateVoiceover`: ElevenLabs TTS لكل مشهد → رفع إلى Storage.
  - `assembleVideo`: في النسخة الأولى = عرض سلايدشو متزامن مع الصوت داخل المتصفح + خيار تنزيل ZIP (صور + صوت + SRT). MP4 حقيقي عبر خدمة خارجية يُضاف لاحقًا.

### 3. المسار الكامل للمستخدم
1. لصق رابط → AI يقرأ المحتوى ويولّد سكربت 4-6 مشاهد.
2. الاستوديو يفتح، تُولَّد صور كل مشهد + voiceover تلقائيًا.
3. مشغل المعاينة يشغّل المشاهد بالتسلسل مع الصوت.
4. زر "تنزيل" → ZIP يحوي الأصول + ملف SRT للترجمة.
5. حفظ المشروع تلقائيًا في حساب المستخدم.

## القرارات التقنية (سأختارها نيابة عنك)
- **اللغة**: عربي RTL أساسي + زر تبديل إلى الإنجليزية.
- **الصوت**: ElevenLabs (يتطلب ربط Connector — سأطلبه عند الحاجة).
- **الفيديو**: سلايدشو متزامن في المتصفح + تنزيل أصول (MVP حقيقي، لا واجهة فارغة).
- **AI**: Lovable AI Gateway (نص + صور).
- **المصادقة**: بريد/كلمة سر + Google.
